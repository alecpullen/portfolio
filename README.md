# Portfolio

A personal portfolio and blog built with [Astro](https://astro.build) and deployed on [Cloudflare Workers](https://workers.cloudflare.com).

## Commands

| Command | Action |
|---------|--------|
| `npm run dev` | Start local dev server |
| `npm run preview` | Build and preview with Workers runtime |
| `npm run build` | Build for production |
| `npm run deploy` | Deploy to Cloudflare Workers |
| `npm run check` | Run build, type check, and dry-run deploy |

See [AGENTS.md](./AGENTS.md) for more details.
